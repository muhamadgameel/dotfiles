---
name: snacks-terminal-float-border
description: When snacks terminal is hard to see, add `border = true`.
category: nvim-config
---

Add `win.border = true` to the snacks terminal config to render a border following your global `winborder` setting (typically `rounded`). A borderless float visually merges with the editor background, making it hard to distinguish. The border is drawn in your theme's FloatBorder color, matching other floating windows.
